# Referencia: Identidad Visual UNL / FBCB

> Extraído del Manual de Identidad UNL (Dirección de Comunicación, 2017) y el Sistema Marcario (2022).
> Para uso interno del proyecto SUME Dashboard y futuras aplicaciones institucionales.

---

## 1. Marca institucional — Universidad Nacional del Litoral

### Efebo (Sello)
- Sello de garantía de la UNL, reservado para piezas de alta jerarquía institucional.
- Se trabaja siempre en monocromo (K:100, K:50, K:40, K:0).
- Versiones: V01 (65–36 mm), V02 (35–26 mm), V03 (25–15 mm).
- Área de protección: perímetro de 1r alrededor del signo.
- Solicitar archivos en DIRCOM.

### Módulo UNL
- Elemento central del sistema de identidad visual. Asume el carácter de marca.
- Reducción mínima: 10 mm de alto.
- Color institucional: **Pantone 314C** — C:100 M:27 Y:25 K:0 — **HTML: #0088AA**

| Versión | Fondo | Módulo 1 | Módulo 2 | Leyenda |
|---------|-------|----------|----------|---------|
| Positiva | K:0–K:40 | K:100 | K:70 | K:80 |
| Negativa | K:50–K:100 | K:0 | K:30 | K:0 |

- Versiones cromáticas disponibles: K:100, K:50, K:40, K:0, y color Pantone 314C.
- Leyenda: Franklin Gothic Demi, mayúsculas, centrada.
- Área de protección: perímetro de 1/3M.

### Módulos complementarios — Unidades Académicas
- Separación entre módulos (UNL + Unidad): 1/3 de la altura (a = M/15).
- Separación módulos–leyenda: 4a, con altura de leyenda de 5a (1/3 de M).
- Leyenda A: Franklin Gothic Demi | Leyenda B: Franklin Gothic Book.
- Área de protección: 1/3M.

## 4. Tipografía institucional

**Familia oficial:** ITC Franklin Gothic Std

| Variable | Uso |
|----------|-----|
| Demi | Títulos, leyendas de módulos |
| Medium | Subtítulos |
| Book | Texto cuerpo |
| Heavy | Énfasis fuerte |
| Italic variants | énfasis cursivo |

- Para comunicaciones web y digitales se admite **Montserrat** (headings) y **Lato** (body) como equivalentes web.
- La página oficial de FBCB usa Montserrat + Lato.

## 5. Módulos especiales

### UNL Virtual
- Rectángulo construido a partir de la relación áurea del módulo cuadrado UNL.
- Color: **Pantone 314C / #0088AA**
- Sep. módulos–leyenda: 4a, altura leyenda: 5a.
- Sep. interna: 1/6M centrada verticalmente.

## 6. Usos incorrectos (resumen)

- Nunca distorsionar, recortar o modificar los signos.
- No cambiar proporciones ni colores fuera de la gama cromática.
- No invadir el área de protección.
- No usar tipografías no autorizadas para la marca.
- El efebo se reserva para piezas de alta jerarquía; el módulo UNL es el uso cotidiano.

## 9. Aplicación en SUME Dashboard

Los tokens CSS del dashboard están alineados con este manual:

```css
/* FBCB institutional green — Pantone 355C */
--fbcb-green: #00A94F;
--fbcb-green-hover: #008C41;
--fbcb-green-light: #b2e8c4;
--fbcb-green-50: #f0fdf4;
--fbcb-green-100: #dcfce7;
```

- Header topbar: fondo `--fbcb-green` con logos blancos SVG.
- Fondo de página: `--fbcb-bg: #f0fdf4` (verde muy claro).
- Tipografías web: Montserrat (headings) + Lato (body).
